🛠️ TECHNICAL DETAILS (For Curious Minds)

What Happens Behind the Scenes:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. generate-images.ps1 (PowerShell script)
   - Scans all image folders
   - Finds all image files (jpg, png, gif, webp)
   - Creates a JSON file with all image paths

2. images.json (Auto-generated file)
   - Lists all gallery images by category
   - Lists all special images (hero, about, services)
   - JavaScript reads this to load gallery

3. script.js (JavaScript)
   - Fetches images.json when page loads
   - Dynamically creates gallery items
   - Sets up lightbox, filters, animations
   - Loads hero/about/service images

Benefits:
✅ No manual HTML editing
✅ Add 100 images at once - just run script
✅ Easy to maintain and update
✅ Works perfectly with GitHub Pages
✅ Fast and efficient

💡 TIPS & BEST PRACTICES

1. Image Quality:
   ✅ Take clear, well-lit photos
   ✅ Focus on the mehandi design
   ✅ Any mobile photo works - no editing needed!

2. File Size (Optional):
   🔧 Compress large images at tinypng.com
   🔧 Recommended: Keep under 2MB each
   🔧 For faster website loading

3. Organization:
   📁 Keep images organized by category
   📁 Delete blurry/unwanted photos before running script
   📁 Remove ADD_IMAGES_HERE.txt files after adding photos

4. Version Control (GitHub):
   📤 Commit images.json along with image files
   📤 Script auto-generates images.json - don't edit manually
   📤 Re-run script whenever you add/remove images

❓ TROUBLESHOOTING

Q: Gallery shows placeholder images
A: Run UPDATE-GALLERY.bat to generate images.json

Q: Images don't appear after running script
A: Check console (F12 in browser) for errors
   Ensure images.json exists in root folder
   Refresh browser (Ctrl+F5)

Q: Can't run UPDATE-GALLERY.bat
A: Right-click > Run as Administrator
   Or run PowerShell script directly

Q: Some images missing from gallery
A: Ensure images are in correct folders
   Check file extensions (.jpg, .png supported)
   Re-run UPDATE-GALLERY.bat

Q: How to remove images?
A: Delete from folder, re-run UPDATE-GALLERY.bat

Q: Need to update live website?
A: After running script:
   1. git add .
   2. git commit -m "Update gallery images"
   3. git push
   Website updates automatically!
