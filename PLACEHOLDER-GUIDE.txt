🔄 HOW TO REPLACE (3 EASY WAYS):

Method 1: Drag & Drop (EASIEST!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Find your photo
  2. Drag it over the placeholder file
  3. Windows will ask "Replace file?" → Click YES
  4. Done! ✅

Method 2: Copy & Rename
━━━━━━━━━━━━━━━━━━━━━━
  1. Copy your photo to the correct folder
  2. Rename it to match the exact name (e.g., hero-bg.jpg)
  3. Windows will ask to replace → Click YES
  4. Done! ✅

Method 3: Delete & Add
━━━━━━━━━━━━━━━━━━━━━━
  1. Delete the placeholder file
  2. Copy your photo to that folder
  3. Rename to exact name (e.g., about.jpg)
  4. Done! ✅

❓ TROUBLESHOOTING:

Q: I replaced images but don't see them on website
A: Did you run UPDATE-GALLERY.bat after replacing?
   Also try refreshing browser (Ctrl+F5)

Q: Can I use PNG instead of JPG?
A: Yes! Any format works (.jpg, .jpeg, .png, .webp, .gif)

Q: What if my photo name is different?
A: Just rename your photo to match the placeholder name
   OR drag it over the placeholder (it auto-renames)

Q: Can I change the placeholder names?
A: Not recommended - the script looks for these exact names
   Just replace the files instead!
